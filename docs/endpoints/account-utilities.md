# Account & Utilities

Manage your account, monitor API usage and credits, and rotate your API key.

**3 endpoints** across **1 category**. Requests need your API key unless noted otherwise. See [Authentication](../authentication.md).

## Categories

### [Account](account.md)

Account, API key, and usage utilities

3 endpoints:

- **Rotate API Key**: `GET /v1.0/api-key/rotate`
- **Account Usage**: `GET /v1.0/whoisapi/usage`
- **Database File Status (Public)**: `GET /v3.4/status`
